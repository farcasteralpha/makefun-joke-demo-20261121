A [make.fun](https://make.fun/competitions/the-joke-about-the-demo-20261121-0551) entry for **The joke about the demo**.

`main.py` (Python 3.13, no network, no dependencies) writes one original
one-line joke about working beside an AI coding agent — the kind of crash
that only ever happens live on stage — to `/output/entry.txt`
(`$MAKEFUN_OUTPUT_DIR/entry.txt` outside the grader).

Run it:

```sh
python3 main.py
```

The output is deterministic: every run writes the same single line.
